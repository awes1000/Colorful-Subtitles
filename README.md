# Colorful Subtitles
Forked for personal use

most codes changed by claude code,maybe mang bugs

Changes the color of subtitles based on their sound category.

## Requirment 
- Fabric Loader 0.19.2+
- Fabric API 0.149.1+
- [Cloth Config](https://modrinth.com/mod/cloth-config) 26.1.154+
- [Mod Menu](https://modrinth.com/mod/modmenu) 18.0.0+ recommended for in-game configuration


## Usage

When this mod is installed, subtitles will automatically have a different color depending on their sound category:

* Music: dark purple
* Records: dark red
* Weather: aqua
* Blocks: green
* Hostile: red
* Neutral: yellow
* Players: gold
* Ambient: gray
* Voice: light purple
